# Terminal Log

- pwd - shows current directory
- ls - lists files
- ls -la - lists hidden files
- mkdir daily-challenges - created folder
- cd daily-challenges - went into folder
- touch day1.md - created file
- git status - checked status
- git checkout -b feature/terminal-log - created branch
- git add . - added files
- git commit -m "Add: terminal log" - saved changes
- git checkout main - went back to main
- git merge feature/terminal-log - merged branch
- git branch -d feature/terminal-log - deleted branch
